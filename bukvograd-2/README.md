# Буквоград 2.0 — Ожившие слова

Откройте `index.html` в браузере. Файл работает сам по себе: можно скачать его и играть без сети. Установка и сервер не нужны.

- **Играть:** послушай целое слово и выбери одну из трёх картинок. Запись можно повторить; «По картинке» показывает образец вместо записи. При выключенном или недоступном звуке образец появляется сам. Неподходящую картинку можно заменить; правильное слово появляется только после верного выбора. Четыре раунда без таймера и штрафов.
- **Мастерская** доступна сразу. Выбери первую букву, чтобы получить картинку-цель: ДОМ ⇄ СОМ или МАК ⇄ РАК. Хвост остаётся на месте, меняются рисунок и запись целого слова. После двух превращений можно свободно менять буквы или повторить задание.

Локально и только по ключу `bukvograd-2-v1` хранятся настройки звука/образца и отметки о завершении. Незавершённый раунд не сохраняется. Если браузер не даёт писать в хранилище, игра работает в текущей вкладке.

## Сборка и проверка

Из этого каталога:

```sh
python3 -B build.py
python3 -B build.py --check
node --test test/model.test.cjs
python3 -B test/browser.py --out /root/projects/gamedev/verification/games-2/letters
```

Сборка и проверки сверяют голос с `../bukvograd/src/clips.json` и пятью исходными MP3 из `../bukvograd/audio/`; готовому HTML эти файлы не нужны. `src/voice.json` фиксирует точные тексты и SHA-256 звука Юлии: `ph_listen` — «Посл+ушай.», `w_dom` — «д+ом», `w_som` — «с+ом», `w_mak` — «м+ак», `w_rak` — «р+ак». Последние четыре — записи целых слов, не отдельные звуки; новые записи не создавались. Иллюстрации — оригинальные SVG в `src/art/`.

Браузерные тесты требуют уже установленный Chromium и Python Playwright (`--chromium` позволяет указать бинарник). Техническая проверка браузера не заменяет проверку слухом, на физическом устройстве или семейный плейтест.
