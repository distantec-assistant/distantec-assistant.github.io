# Цифроград: экспериментальная площадка

## Контекст и границы
- Целевая аудитория: дети около 4 лет, уже играющие в маршрут «До 30».
- Запрос: добавить все три предложенные механики и улучшить графику, чтобы семья могла выбрать подходящие занятия.
- Публикация — отдельный путь `/tsifrograd-lab/`; существующие `/tsifrograd/`, Буквоград, каталог, CNAME и их сохранения не изменять.
- Без внешних библиотек, покупных ассетов, серверного хранилища и платных API во время игры. Разовая генерация озвучки SpeechKit отдельно согласована.
- Новая графика — оригинальные SVG/CSS. Текущая озвучка — готовые записи Edge TTS `ru-RU-SvetlanaNeural` в `audio-svetlana/`; общие числа и похвала берутся из такого же банка обычного Цифрограда. Старая Юлия остаётся в `audio/` для отката. Голос меняется по отдельному запросу, механики и сохранения — нет.

## Игры
1. Заказы: набрать заданное количество до 30 десятками и единицами, добавлять и убирать, самому отправлять. Допускать лишнее количество для самостоятельного исправления, не автозавершать.
2. Угости поровну: перераспределить фиксированное чётное количество угощений между двумя пассажирами. При каждом перемещении сохраняется общее число; ребёнок сам проверяет результат.
3. Мост: собрать длину из деталей 1, 2, 5, 10. Допускать короткий/длинный мост, удаление любой детали, явную проверку. Поезд едет после правильного решения.

## Реализация
- `model.mjs`: чистые функции создания задач, добавления/удаления деталей, перемещения угощений и проверки решения; детерминированные разнообразные раунды; тесты `model.test.mjs` через `node --test`.
- `art.mjs`, `art.css`: оригинальные персонажи, поезд, предметы и сцены; никаких сторонних изображений.
- `index.html`, `app.mjs`, `style.css`: самостоятельная игра с выбором каждой механики, смешанным маршрутом, понятными крупными кнопками, отдельным сохранением `tsifrograd-lab-v1`, повторами, мягкой обратной связью.
- `README.md`: концепция, управление, записанная озвучка, проверенное/ограничения, запуск и откат.
- Регрессионные проверки браузером: все три игры от старта до успеха, неправильные ответы и исправления, повтор, переход домой, сохранение, испорченное сохранение, отсутствие вмешательства в `tsifrograd-v1`, мобильная и планшетная компоновка, reduced motion, ошибки JS и ресурсы.

## Проверка и выпуск
- Сделать скриншоты текущей игры и новой версии, проверить графику на реальных размерах рендера.
- Бюджет ревью: одна проверка соответствия заданию, затем одно ревью качества/корректности; до одного адресного перепроверочного раунда для существенных замечаний каждого этапа. Стиль не блокирует выпуск.
- До отправки: тесты, `git diff --check`, отсутствие изменений старых игр, проверка актуального `origin/main` и не перезаписывать чужие изменения.
- Публиковать только новую папку. Откат — убрать добавленную папку отдельным коммитом; прежние игры не требуют восстановления.
- После публикации прочитать GitHub-ветку и проверить live URL/версию/игровые действия, не считать успешный push подтверждением доступности.
- Нельзя утверждать реальную проверку ребёнком, на физическом iPad/iPhone или качество слышимого звука по одним автоматическим тестам.
