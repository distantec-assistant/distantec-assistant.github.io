Для родителей · что это за версия

Это отдельная площадка для проверки новых занятий. Прогресс привычного Цифрограда не меняется. Здесь сохраняется только число выполненных заданий и настройка звука — на этом устройстве, без регистрации и отправки данных.

Новые иллюстрации нарисованы специально для этой версии. Инструкции, числа и подсказки озвучены голосом Юлия. Готовые записи загружаются как обычные аудиофайлы; русский системный голос на устройстве не нужен. Сайт не обращается к API синтеза и не содержит ключей.

Не удалось загрузить часть озвучки. Проверьте интернет и нажмите «Послушать задание» ещё раз.
