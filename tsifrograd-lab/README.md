# Цифроград — новые приключения

Отдельная экспериментальная версия для ребёнка 4 лет, который уже играет в маршрут «До 30». Проверяем разнообразие действий, а не увеличение диапазона чисел.

## Играть

Адрес версии: https://games.distantec.app/tsifrograd-lab/

На главном экране доступны все три занятия без прохождения других уровней. «Всё путешествие» последовательно проводит через каждое. Успех подтверждается только кнопкой ребёнка, а не автоматической остановкой на правильном количестве. Нет таймера, жизней и потери награды из-за ошибки.

- **Заказы для пассажиров.** Добавляйте коробки по десять яблок и отдельные яблоки. Нажатие на добавленный предмет убирает его. Соберите нужное количество и отправьте заказ; лишнее можно исправить.
- **Угости поровну.** Нажатие на тарелку переносит одно угощение другому пассажиру. Общее число не меняется. Когда на тарелках поровну, нажмите проверку.
- **Построй мост.** Выбирайте детали длиной 1, 2, 5 и 10. Нажатие на добавленную деталь в нижнем ряду убирает её. Поезд поедет после проверки моста нужной длины.

Кнопка с домиком возвращает к выбору, динамик повторяет задание, круговая стрелка начинает задание заново. Глобальная кнопка звука выключает и речь, и записанные числа. Управление — нажатия пальцем, мышь или клавиатура; обязательного перетаскивания нет.

## Графика и звук

- Персонажи, паровоз, предметы и три разные сцены — оригинальные SVG/CSS этой версии. Сторонние изображения и внешние шрифты не используются; в процессе игры нет вызовов платных API. Генерация новых записей SpeechKit выполнена отдельно при сборке по согласованию.
- Сохранены кремовый фон, дружелюбный поезд и кораллово-мятная палитра Цифрограда. Новое: пассажиры, разные места действия, видимые заказы/тарелки/мост, предметные кнопки и размерный ориентир моста.
- Числа и похвала загружаются из существующей `../tsifrograd/audio/`. Новая страница сама не обращается к Yandex SpeechKit или другим API генерации голоса.
- Новые инструкции и числа 31–40 записаны через Yandex SpeechKit v3, голос `julia`, амплуа `neutral`. В браузере нет зависимости от Web Speech API. При ошибке загрузки показывается предупреждение, повтор задания повторяет загрузку недоступного файла.
- Тексты и параметры — `tts/clips.json`; генератор — `tts/generate.py`. Он читает `YANDEX_API_KEY` только из защищённого окружения, создаёт лишь отсутствующие/изменённые записи, проверяет MP3 и сохраняет манифест. Не передавайте ключ аргументом команды и не сохраняйте его в репозитории. Ключ, использованный для этого выпуска, отдельно не сохранялся.
- Движение отключается при `prefers-reduced-motion: reduce`.

## Сохранения и границы

Отдельный ключ: `tsifrograd-lab-v1`. Сохраняются счётчики выполненных задач и звук. Текущее незавершённое задание после перезагрузки не восстанавливается; завершённые результаты сохраняются. При недоступном хранилище игра продолжает работать с видимым предупреждением.

`tsifrograd-v1` и `bukvograd-v1` не читаются и не меняются. Старый Цифроград, каталог и другие игры остаются прежними. Новая страница помечена `noindex,nofollow`, ссылки из каталога пока нет.

## Запуск и проверки

Из корня репозитория:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
# http://127.0.0.1:8080/tsifrograd-lab/
node --test tsifrograd-lab/*.test.mjs
python3 tsifrograd-lab/test-browser.py
python3 tsifrograd-lab/test-voice.py
```

Браузерный сценарий использует Python Playwright и уже установленный Chromium, сам поднимает временный loopback-сервер. `LAB_CHROME` задаёт путь к браузеру; `LAB_QA_OUT` — каталог результатов. Для проверки опубликованной версии: `LAB_BASE_URL=https://games.distantec.app python3 tsifrograd-lab/test-browser.py`. Все сохранения тестов создаются в изолированных браузерных профилях, не в пользовательском браузере.

Результаты реального запуска и оставшиеся ограничения фиксируются в `VERIFICATION.md` перед выпуском. Автоматическая проверка не подтверждает интерес ребёнка, физический тач на iPad/iPhone или качество слышимой озвучки.

## Решения и следующий шаг

Пока все механики доступны отдельно, чтобы семья могла сравнить их. Не включать их принудительно в каждую обычную станцию до обратной связи. Наблюдать, понятна ли задача без постоянных объяснений, пробует ли ребёнок менять решение и хочет ли ещё один раунд. Решение о включении в основной Цифроград — после этого. По отдельному запросу временный голос устройства заменён записанной Юлией v3.

## Откат

Версия добавляет только папку `tsifrograd-lab/`. Для удаления опубликуйте отдельный коммит, убирающий эту папку. Старые игры и их сохранения не требуют восстановления. Не использовать force-push или reset общей ветки.
