Свежие отчёты родителя: `parent-local/browser-20261115T082559.568831Z-fb28d76e/` и `parent-local/voice-20261115T082809.856625Z-fc86b270/` внутри `/root/projects/gamedev/verification/tsifrograd-lab-v2/`. Следующие обязательные гейты: заморозить кандидат по хешам, независимое spec-review, затем quality/security-review. Их атрибутированные вердикты и окончательная live-приёмка хранятся рядом с замороженным манифестом вне репозитория, чтобы не менять уже проверенный источник. Живой сайт считается обновлённым только после exact-head Pages success, byte readback и повторных live игровых/голосовых сценариев. Основной Цифроград не переносится в v2 автоматически.

Ограничения: семейный плейтест, слышимая фонетика/громкость, физические устройства и Safari не подтверждены. Новый порядок сложности — обоснованное проектное решение, не доказательство подходящего уровня для конкретного ребёнка.

План и границы — `PLAN.md`, графическое направление — `DESIGN.md`. Основной Цифроград, остальные игры и старые сохранения в эту миграцию не входят.

## Контроль публикации

После push отдельно проверяются GitHub `main`, совпадение байтов опубликованных HTML/JS/CSS с выпущенными файлами, HTTP/MIME и прохождение браузерного сценария по живому URL. Старые главная, CNAME, Цифроград, Буквоград и Лабиринты сравниваются с исходными SHA-256. Успешный push сам по себе не считается подтверждением публикации.
