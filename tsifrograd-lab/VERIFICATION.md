## Контроль публикации

После push отдельно проверяются GitHub `main`, совпадение байтов опубликованных HTML/JS/CSS с выпущенными файлами, HTTP/MIME и прохождение браузерного сценария по живому URL. Старые главная, CNAME, Цифроград, Буквоград и Лабиринты сравниваются с исходными SHA-256. Успешный push сам по себе не считается подтверждением публикации.
