# Что дальше? 2.0 · Праздник узоров

Первый семейный эпизод, отдельный от игры `uzory/`. «Играть» открывает два коротких задания: выбрать недостающий фонарик из двух, затем собрать полный ряд из шести по видимому образцу. Во второй задаче нажатие на фонарик ставит его на выбранное место; следующее пустое место отмечается само. Кнопка «Проверить» ничего не стирает, а указывает первую незаполненную или неверную позицию. Можно заменить любой фонарик, в том числе после успеха. Нет таймера и ограничения по числу попыток.

«Моя гирлянда» доступна сразу. Игрок собирает кусочек из 1–4 деталей; экран показывает три полных повтора. Нажатие на деталь выбирает её для замены или удаления; без выбора «Убрать» удаляет последнюю. Здесь нет правильного ответа.

- `python3 -B uzory-2/build.py` встраивает CSS, JS, рисунки и пять записей Юлии из прежних «Что дальше?». Браузер не обращается к сети, к старой игре или к TTS. `--check` сверяет байты сборки. Откройте собранный `uzory-2/index.html` в обычном браузере; установка не нужна.
- `node --test uzory-2/test/model.test.cjs` проверяет правила. `python3 -B uzory-2/test/browser.py --out /path/to/evidence` проверяет сценарии в Chromium, в том числе сборку из файла офлайн. Dev-зависимости только для проверок: Node.js, Python с Playwright и установленным Chromium.
- Новый `localStorage`-ключ `uzory-2-v1` хранит отметки двух заданий, звук и свободный кусочек. Незавершённое задание после закрытия не хранится. Скачанный файл и HTTPS могут использовать разные хранилища. Если сохранение недоступно, в открытой вкладке всё равно можно играть.

Семейная проба: дать ребёнку первым нажать «Играть». Сработает ли переход от выбора одного фонарика к заполнению всего ряда, понятно ли, что один отмеченный фонарик можно заменить, хочется ли собрать свой? Реальный плейтест, физические касания и Safari не проверялись. Публичный сайт и каталог на этапе прототипа не меняются.
