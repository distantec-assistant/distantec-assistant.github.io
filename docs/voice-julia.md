# Активная озвучка: Юлия

По запросу Андрея после сравнения со Светланой возвращены прежние записи Юлии. Активны:

- `bukvograd/audio/` — 523 MP3;
- `tsifrograd/audio/` — 106 MP3, включая 13 общих реплик Буквограда;
- `tsifrograd-lab/audio/` — 21 собственный MP3; числа 1–30 и похвала берутся из `../tsifrograd/audio/`.

Все 651 файл исходных банков, включая lab-манифест, побайтно совпадают с выпуском `cab11066edb45f9e64f454bb321d362514d0254d`. Синтез не выполняется, ключ SpeechKit не нужен, платных запросов нет. Никакие секреты в сайт не добавляются.

## Источники и кэш

Загрузчики обычных игр возвращены к `audio/` в исходных шаблонах и пересобранных HTML. Исходник общей реплики в `bukvograd/src/data.py` и `clips.json` снова соответствует Юлии: «Выбери станцию, и поехали!». Выбранный позднее вариант «Начинаем путешествие» записан только Светланой и остаётся в её архивном банке.

Карта lab использует только `audio/`; HTML загружает `app.mjs?v=4`, а приложение — `narration.mjs?v=4`. Обе зависимости получили новую кэш-версию. Старые открытые вкладки нужно перезагрузить.

Оба набора MP3 сохранены без изменения байтов. Механики, задания, графика, каталог, CNAME и ключи сохранений не меняются.

## Проверки

```sh
GAME_AUDIO_BANK=audio python3 tools/test_svetlana_browser.py
node --test tsifrograd-lab/*.test.mjs
python3 tsifrograd-lab/test-browser.py
python3 tsifrograd-lab/test-voice.py
```

Имя общего браузерного теста историческое: `GAME_AUDIO_BANK=audio` требует Julia-пути и считает запросы к `audio-svetlana/` ошибкой. Для живого сайта добавляется `LAB_BASE_URL=https://games.distantec.app`. Тестовые сохранения находятся в изолированных профилях Chromium, не в пользовательском браузере.

При возврате все 650 MP3 проходят полное декодирование; дополнительно проверяются страницы, карта, номера кэш-версий и воспроизведение из опубликованных путей. Техническая проверка не заменяет слушание, Safari или физическое устройство.

Все 653 файла `audio-svetlana/` сохранены, включая выбранную стартовую реплику. Исторические источники и проверки Светланы согласованы с выпуском `5341466b6f80318c45c4fc1eecd20e076645f11c`; её миграционные тесты не являются текущей приёмкой Юлии.
