# Озвучка Светланы: устройство, проверки и откат

## Что переключается

Активный голос трёх обучающих страниц — `ru-RU-SvetlanaNeural` через `edge-tts`. Буквоград, обычный Цифроград и экспериментальный Цифроград используют заранее созданные MP3 из своих `audio-svetlana/`. Общие числа и похвала эксперимента берутся из `../tsifrograd/audio-svetlana/`.

Идентификаторы звуков, игровые правила, прогресс и ключи `localStorage` не меняются. Старые банки Юлии в `audio/` сохранены побайтно. Новый путь исключает смешивание голосов из старого браузерного кэша; при смене карты модулей эксперимента также увеличен номер версии JS.

Целевой набор миграции: 523 файла Буквограда, 106 обычного Цифрограда, 21 экспериментального. Общие реплики генерируются один раз и копируются в нужные банки, а не заменяются голосом другого провайдера.

## Тексты и особые случаи

Источники остаются в `bukvograd/src/clips.json`, `tsifrograd/src/clips.json`, `tsifrograd-lab/tts/clips.json`. У Цифрограда есть 13 переиспользуемых фраз из Буквограда, перечисленных в `src/data.py:REUSE`.

`tools/svetlana_audio.py` готовит текст для Edge:
- `+` перед ударной гласной в многосложном слове переводится в Unicode-акут после гласной; для односложных слов знак убирается. После `ё` второй знак не добавляется.
- Старая разметка Ы `[[ɨ]]` заменяется обычной буквой. Неизвестная фонемная разметка вызывает остановку, а не проговаривается вслух.
- Отдельное О и слог О используют выбранный сравнительный вход `О-о-о!`; звуковое упражнение повторяет его трижды. Остальные отдельные гласные — собственные запросы, не вырезанные из алфавита.
- Номера сохраняют умеренно замедленную подачу. Меняется голос, не высота или скорость готового аудиофайла.

Сервис принял примеры с Unicode-ударениями и вернул корректно декодируемое аудио. Это **не доказательство правильности всех ударений на слух**. Названия букв, учебные звуки, слоги и слова — разные записи; после семейного прослушивания конкретные исключения можно уточнять отдельно.

## Воспроизводимая генерация

Из корня репозитория, с установленными `edge-tts` и `ffmpeg` (этот набор создан с `edge-tts` 7.3.1):

```sh
python3 tools/test_svetlana_audio.py
python3 tools/svetlana_audio.py --cache-dir ../cache/edge-svetlana --plan-only
python3 tools/svetlana_audio.py --cache-dir ../cache/edge-svetlana --max-new 700 --interval 1.1
python3 bukvograd/src/build.py
python3 tsifrograd/src/build.py
```

Для новых слов сначала обновляется исходник данных, затем запускается генератор данных **из его каталога** (например, `cd bukvograd/src && python3 data.py`), после чего общий генератор создаёт недостающие записи. Новой записи не нужна старая запись Юлии.

Кэш хранится вне репозитория. Ключ кэша связывает нормализованный текст, голос, темп, высоту и алгоритм обрезки. Он проверяет фактический SHA-256 файла. Запросы выполняются последовательно с паузой; разрешён один ограниченный повтор только для временных сетевых/серверных ошибок. Обход ограничений сервиса не используется. После каждого результата есть контрольная точка; сбой не требует повторять весь набор.

Убирается только внешняя техническая тишина по таймингам слов с запасом. Внутренние паузы не вырезаются. Каждый файл проходит ffprobe, полное декодирование и проверку наличия звукового участка. Манифесты банков содержат исходный и нормализованный тексты, параметры, длительности, SHA-256 и `complete`.

Синтез — отдельный шаг сборки. Во время игры нет обращений к Microsoft/Yandex/Gemini для генерации речи, ключей, платных запросов или зависимости от системного русского голоса. Условия публичного/коммерческого использования сервиса и отсутствие у сторонней обёртки договорного SLA нужно учитывать отдельно; бесплатный доступ не является обещанием вечной доступности API.

## Проверка перед публикацией

```sh
python3 tools/test_svetlana_assets.py --compare-baseline cab11066edb45f9e64f454bb321d362514d0254d
python3 tools/test_svetlana_browser.py
node --test tsifrograd-lab/*.test.mjs
python3 tsifrograd-lab/test-browser.py
python3 tsifrograd-lab/test-voice.py
```

Проверяется весь набор файлов и соответствие манифестам, неизменность Юлии, реальные запросы и декодирование, интро букв, оба числовых маршрута, все экспериментальные занятия, отмена/повтор звука, отсутствие старых путей в запросах активной игры и сохранения. После публикации те же браузерные сценарии запускаются с `LAB_BASE_URL=https://games.distantec.app`; новые MP3 сравниваются с локальными выпущенными байтами.

Автоматизация не заменяет физический iPhone/iPad/Safari, прослушивание динамиков и оценку ребёнком. Статус проверок выпуска фиксируется отдельно; наличие этого описания само по себе не означает PASS.

### Выполненная локальная приёмка этого набора

- Полное декодирование, SHA-256 и метаданные: **650/650 PASS**; сравнение **651** файла прежних банков с `cab11066edb45f9e64f454bb321d362514d0254d` — без изменений.
- Нормализация/генератор: **8 Python-тестов**; модель/прогресс/карта: **41 Node-тест** — PASS.
- Общая миграционная проверка: **16/16 сценариев** Chromium на телефоне/планшете, с наблюдением настоящих fetch/decode/WebAudio и проверкой сохранений.
- Дополнительный lab-regression: **14/14** игровых проверок и **5/5** групп звука, включая отмену и восстановление после ошибки загрузки; 21 собственный клип декодирован, после сценария активных источников нет.
- Повторная сборка из кэша: **0** новых запросов, все **653** MP3/манифеста остались побайтно теми же.
- Независимые проходы: **spec PASS**, **quality/correctness/security APPROVED**, блокирующих замечаний нет.

После публикации проверяются remote `main`, все новые MP3, манифесты/страницы/карта и выборочные старые записи:

```sh
python3 tools/verify_svetlana_release.py --previous cab11066edb45f9e64f454bb321d362514d0254d
LAB_BASE_URL=https://games.distantec.app python3 tools/test_svetlana_browser.py
```

Verifier рассчитан на чистое рабочее дерево именно опубликованного коммита; он сравнивает HTTP-ответы с его локальными байтами. Подробные независимые отчёты и результаты живого readback сохраняются отдельно от исходников в документации проекта, а не превращаются в утверждение о проверенном произношении.

## Одобренная стартовая реплика

Общая реплика `ph_pick_station` в Буквограде и обычном Цифрограде заменена на **«Выбери станцию. Начинаем путешествие!»** — выбранный Андреем третий образец. Использован именно выбранный MP3, побайтно одинаковый в обоих банках, без повторного синтеза. Исходник `PHRASES` и сгенерированный `clips.json` обновлены согласованно; Цифроград по-прежнему заимствует эту реплику из Буквограда.

Только для этого ID загрузчики добавляют `?v=station-intro-2`, чтобы старая кэшированная запись не заменила новую. Остальные аудиозаписи, приветствия `ph_hello`, механики и сохранения не изменены. Исправление этой реплики не является заключением о произношении всех остальных записей.

## Откат без потери прогресса

1. Вернуть `fetch('audio/'+id+'.mp3')` в двух исходных шаблонах и пересобрать их HTML.
2. Вернуть старые `audio/` в `tsifrograd-lab/narration.mjs`, увеличив версии импорта карты и приложения, чтобы не остался кэш новой карты.
3. Опубликовать отдельным обычным коммитом. **Не удалять `audio-svetlana/` сразу:** уже открытые вкладки с новой версией должны продолжать получать свои файлы.

Старые `audio/` уже находятся в репозитории; локальная дополнительная копия и манифест сделаны до миграции. Ключи и содержание сохранений для отката менять не нужно. Force-push и сброс общей ветки не используются.
