# Цифроград 2.0

Самостоятельная игра каталога: **https://games.distantec.app/tsifrograd-2/**.

Выпущена по команде Андрея отдельной карточкой, не заменяет привычный `/tsifrograd/`. Проверенная интегрированная версия из `/tsifrograd-lab/` перенесена в свой каталог, чтобы будущие эксперименты лаборатории не меняли опубликованный runtime. Лаборатория тоже остаётся доступной.

## Игра

Пять станций: Лужайка 1–5, Лес до 10, Город 11–20, Мастерская самостоятельных задач, Большое путешествие до 30. Девять механик и короткие путешествия по два задания. Заказы, угощение поровну и мосты доступны только на двух старших станциях; уровень не повышается автоматически. Все станции можно выбрать явно. Нет таймера, потери награды за ошибку и обязательного перетаскивания.

Игровые правила, оригинальные SVG/CSS и сохранённая Юлия перенесены без изменений. Новый синтез, внешние библиотеки, шрифты, платные API и серверное хранение не используются.

## Сохранения и зависимости

Новый собственный ключ: **`tsifrograd-2-v1`**. Автоматической миграции прогресса из лаборатории или прежнего Цифрограда нет; новая версия начинает с Лужайки. Старые данные остаются на месте, а все пять станций доступны сразу.

Приложение не читает и не меняет `tsifrograd-v1`, `bukvograd-v1`, `tsifrograd-lab-v1` и `tsifrograd-lab-v2`. В тестах они представлены точными непрозрачными строками.

Свои инструкции/числа 31–40 находятся в `audio/`; неизменный `tts/clips.json` сохраняет их исходные тексты для unit-проверки, без генератора и ключей. Общие сохранённые записи берутся из `../tsifrograd/audio/` и `../bukvograd/audio/`. Эти банки защищены от изменения и не требуют доступа к провайдеру озвучки. `-lab` не является runtime-зависимостью опубликованной версии.

## Проверки

Из корня репозитория:

```sh
node --test tsifrograd-2/*.test.mjs
python3 tsifrograd-2/test-browser.py
python3 tsifrograd-2/test-voice.py
```

Браузерные сценарии используют уже установленный Chromium в изолированном профиле, по умолчанию временный loopback-сервер. Поддерживаются `LAB_BASE_URL=https://games.distantec.app`, `LAB_CHROME`, `LAB_QA_OUT`, `VOICE_QA_OUT`. Название переменной `LAB_BASE_URL` сохранено для совместимости с проверенным QA; путь и сохранение уже относятся к самостоятельному `tsifrograd-2`.

Исходный код механик получил spec-PASS, quality/integration-APPROVED и реальные unit/browser/WebAudio проверки в выпуске лаборатории `72a2239cd11655fdc1ad971e4fffafe4d2427021`. Для отдельной публикации дополнительно проверяются literal-only различия брендинга/ключа, независимость старых приложений и сохранений, новая карточка, обложка и полный сценарий по новому URL. Артефакты — `verification/tsifrograd-2-release/` вне репозитория.

Автоматическая приёмка не заменяет семейную проверку понятности, слышимого качества и физического тача/Safari. Карточка не означает подтверждённое освоение всех задач ребёнком.

## Изменения и откат

Область выпуска: новая папка `tsifrograd-2/`, её новая обложка `tsifrograd-2.webp` и один добавленный блок в основном каталоге. Старые карточки, игры, лаборатория, аудиобанки и CNAME неизменны.

Откат — отдельный обычный commit, удаляющий только новую карточку, папку и обложку. Не откатывать всю общую ветку, не использовать force-push и не удалять старые сохранения.
