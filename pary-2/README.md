# Найди пару 2.0 — Фотоальбом

Короткая семейная проба для возраста около 3–5 лет. Откройте **`index.html`** прямо в браузере (`file://`): нужен только этот файл. Вкладки открывают любое задание; «Дальше» ведёт к следующей странице после решения. Можно начать с `#open`, `#closed` или `#missing`.

| Страница | Что решает ребёнок |
|---|---|
| **Пары** | Среди четырёх открытых карточек найти две пары. Найденные карточки остаются на месте с галочкой. |
| **На память** | Среди шести закрытых карточек найти три пары, запоминая места. «Подсмотреть» открывает отдельную раскладку без ходов. После закрытия выбранная карточка и найденные пары остаются. |
| **Кто исчез?** | Посмотреть на троих героев и самому сменить снимок кнопкой «Я запомнил». Среди трёх картинок выбрать пропавшего героя; один кандидат остался на снимке, другого на нём не было. Первое фото можно открыть снова: один просмотр не выдаёт снимок в альбом. |

Две разные карточки остаются видны до выбора другой карточки. Ошибочный ответ можно исправить сразу. Нет таймера, жизней и штрафов. `Tab` / `Shift+Tab` — переход по элементам, `Enter` — активация, `Space` — нажатие кнопки, `Escape` — закрытие подсказки/первого фото. «Снова» даёт свежий раунд и не стирает снимки.

## Сохранение

Одна фотография с галочкой за каждое задание, не за каждое прохождение. Сохраняются только полученные фотографии в `localStorage` под ключом `pary-2-v1`; перезагрузка начинает новый раунд на той же странице. Если браузер не даёт доступа к хранилищу либо запись пустая или повреждённая, игра не переписывает её и держит фотографии только до закрытия/перезагрузки страницы. Запись, которой ещё нет, создаётся при первой победе, если хранилище доступно.

## Сборка и проверка

Из `pary-2/`:

```sh
python build.py                     # собрать index.html из src/
python build.py --check             # сверить байты, ничего не записывая
node --test tests/engine.test.cjs    # модель игровых ходов и хранения
python -B verify.py                 # сборка --check, Node и реальные сценарии Playwright
```

Воспроизводимая сборка использует только Python stdlib. Для последней команды нужны существующие Python Playwright, Chromium и Node; скрипт ничего не устанавливает. При отсутствии браузера из ожидаемой ревизии выбирает Chromium из уже установленного кэша Playwright. Чек и снимки: `../../verification/games-2/pairs/`, включая `result.json` с SHA-256 автономного файла.

Шесть оригинальных SVG, стили и скрипт встроены; без сети и озвучки. Это локальный предпросмотр с `noindex,nofollow`, не публикация. Проверен Chromium с эмуляцией касания, не реальный телефон, Safari или семейная проба с ребёнком. Для ребёнка, который ещё не читает, взрослый может один раз показать, что делать на каждой странице.
