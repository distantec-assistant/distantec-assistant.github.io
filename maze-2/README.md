# Лабиринты 2.0 · Почта тропинок

Зайчик разносит почту: выбери соседнюю тропу, и он дойдёт до следующей развилки. Начни с письма для ежа. У ручья нужно забрать марку до вручения, а дальше встречаются кольцевые тропы и поручения с двумя остановками по порядку. В тупике всегда можно повернуть назад. Таймера и штрафов нет.

В атласе четыре главы по шесть доставок. Любую можно открыть сразу: «Первые письма», «Дальняя почта», «Особые поручения» и «Большое путешествие». Победы отмечаются в альбоме; доставленные письма можно разнести ещё раз.

**Как пользоваться планом.** Третья история про маяк начинается как первые две: одно нажатие — одна тропа. Если включить план, стрелки показывают будущее движение, а зайчик ждёт. Можно убрать последний шаг или отменить весь план без движения. «Пойти» запускает выбранные переходы; если первый шаг приводит к вручению, второго не требуется. На сложной развилке подсказка показывает ближайшую тропу к нужной сейчас остановке, но идти за ребёнка не будет.

**Сохранения.** Игра читает прежний ключ `maze-mail-2-v1` и отмечает завершённые доставки. `meadow`, `stream`, `coast` — те же три истории, поэтому повторно проходить их после обновления не нужно. Незавершённая доставка начинается сначала. Никаких аккаунтов или сетевого хранилища; без доступа к хранилищу играть можно до закрытия страницы. У файла и сайта отдельный прогресс.

**Сборка и проверка** (из корня репозитория):

```
python3 -B maze-2/build.py
python3 -B maze-2/build.py --check
node --test maze-2/test/*.test.cjs
python3 -B maze-2/test/browser.py --out /path/to/new-report
```

`index.html` — автономная игра с авторскими SVG, внешние файлы при запуске не нужны. Маршруты заданы в `src/campaign.cjs`, правила движения и сохранений — `src/model.cjs`. Браузерной проверке нужны Python Playwright и установленный Chromium. Для проверки обновления на том же адресе передай `--prior /path/to/previous/index.html`: тест создаёт настоящие отметки в старом интерфейсе и продолжает игру в новом. `--origin` выполняет прохождение на опубликованном сайте. Автоматические касания в Chromium не заменяют игру ребёнка на реальном устройстве.
