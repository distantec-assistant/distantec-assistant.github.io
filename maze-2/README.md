# «Лабиринты 2.0» · Почта тропинок

Три самостоятельные истории для семейной пробы. У каждой тропинки есть крупная стрелка: герой сам проходит выбранный отрезок до следующей развилки. Можно попробовать другой путь, вернуться в тупике или спокойно выбрать другую карту; таймера нет.

1. **Письмо для ежа.** Выбери тропы по полянке и доставь конверт получателю.
2. **Посылка у ручья.** Загляни на кувшинки за маркой, затем отнеси посылку выдре. Если дошёл до выдры раньше, возвращайся по мосту — ничего не потеряно.
3. **Огонёк для маяка.** Нажми две стрелки, чтобы увидеть будущий маршрут. «Назад» убирает последний шаг, «Отменить» закрывает план без движения, «Пойти» запускает выбранные переходы. На последнем отрезке к маяку достаточно одного перехода. Можно идти по одной тропе.

Игра запоминает только доставленные письма/посылки/огонёк под `maze-mail-2-v1`. Все истории доступны сразу и переигрываются; незавершённый путь не сохраняется. Без хранилища игра продолжает работать. Оригинальная `maze/` имеет свой отдельный прогресс. Этот семейный вариант не меняет каталог и не публикуется автоматически.

- `python3 -B maze-2/build.py` делает автономный `maze-2/index.html`; `--check` сверяет точные байты. Достаточно открыть файл в браузере. Нет сетевых ресурсов.
- `node --test maze-2/test/model.test.cjs` — достижимость, смежность, марка, обратимые тупики, валидный план, корректное завершение и сохранения.
- `python3 -B maze-2/test/browser.py --out /path/to/new-evidence` — реальные маршруты в Chromium с мышью, клавиатурой и эмуляцией касаний; два шага, редактирование, узкий экран, локальное сохранение и офлайн-файл. Нужны Python, Playwright и установленный Chromium.

Для ребёнка полезный вопрос: замечает ли он, что в режиме плана зайчик ещё стоит на месте, и меняет ли второй шаг, когда видит, что тот ведёт в тупик? Семейный плейтест, физическое устройство и Safari не проверялись.
