# Цветная мастерская

Статическая браузерная раскраска. Сначала ребёнок выбирает краску, затем нажимает на любую белую или уже закрашенную деталь. Ластик работает тем же способом и возвращает белую заливку. «Отменить» возвращает предыдущий цвет (до 64 действий на рисунок в текущей вкладке). Нет таймера, правильных цветов, автоматической смены рисунка или заблокированных листов.

В альбоме 20 рисунков, по пять на каждой ступени. «Легко» — 5–7 крупных деталей; «Посложнее» — 8–10; «Много деталей» — 11–14; «Самые подробные» — 15–20. Выбор ступени показывает её рисунки, но не меняет полотно, пока ребёнок не выберет рисунок.

Стартовый лист — воздушный шар. Поздние листы содержат больше самостоятельных областей, а не меняют правила игры. На небольшой ширине палитра под рисунком, на широкой — справа. Мышь и тач используют один клик, для клавиатуры — Tab и Enter/Пробел. Рисунки и последний выбранный лист хранятся только в `raskraska-v1` на этом устройстве. При недоступном хранилище раскрашивание продолжается без сохранения. В общий каталог ведёт кнопка «К играм» только у версии, открытой по HTTP(S).

## Редактирование и проверка

- `src/scenes.json` — четыре первых рисунка, по одному на ступень; новые рисунки добавляются в соответствующий `src/album/*.json`. У каждого рисунка свой стабильный `id`, название, `areas` и `details`. У каждой области уникальный в пределах рисунка `id`, русская подпись `label`, замкнутый SVG-путь `d` (в координатах `0 0 480 360`), внутренняя и неперекрытая точка нажатия `at: [x,y]`, цвет `color` из палитры только для превью. Рисуйте области от задних к передним; `details` — только открытые линии, не отдельные замкнутые области. Стабильные ID сохраняют прежние раскраски. Сборка проверяет отсутствие дублей и неубывающий порядок числа деталей. Проверяйте доступность каждой новой области на узком экране.
- `python3 raskraska/build.py` — детерминированная сборка `raskraska/index.html`. Открывайте этот файл напрямую в браузере или через локальный статический сервер; он не загружает шрифты, скрипты, графику или звук по сети. Перед передачей файла `python3 raskraska/build.py --check` проверяет соответствие исходникам.
- `python3 -B raskraska/make_cover.py` — обложка каталога из первого рисунка и фактической палитры сборки. Для этого dev-инструмента нужны Playwright/Chromium и Pillow; игра не зависит от них.
- `python3 -B raskraska/test_browser.py --out /path/to/core-evidence` — базовая механика, клавиатура, тач, открытие файла офлайн и недоступное хранилище.
- `python3 -B raskraska/test_album.py --out /path/to/album-evidence` — полный альбом и все области в Chromium. Оба прогона используют временный loopback HTTP-сервер, требуют Python Playwright и установленный Chromium. Параметр `--legacy-index` принимает прежний сборочный HTML для проверки совместимости сохранений на одном origin. При расширении альбома обновите матрицу в `test_album.py` и число рисунков в карточке каталога.

Публичный адрес: `https://games.distantec.app/raskraska/`. Браузер не переносит сохранения из скачанного `file:` на `https:`: это разные хранилища. Эмуляция тача не заменяет физическое устройство, Safari или семейный плейтест.
